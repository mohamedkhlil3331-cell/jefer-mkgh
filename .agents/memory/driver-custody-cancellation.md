name: Driver custody cancellation
description: Scope and data-preservation rules for the movement-custody tab under Driver Management.
---

In “عهدة الحركة” under Driver Management, canceling means canceling the print state only. Return the selected statement to “غير مطبوع” while preserving the statement, KH reference, saved snapshots, source items, and batch marks. Do not void the statement or exclude it from custody totals. Treat any old cancellation flag as legacy print-state data, not a deleted or voided statement.

**Why:** The user clarified that canceling should mean the statement was not printed among the selected statements; the original custody statement and its items must remain intact.

**How to apply:** Keep the workflow in Driver Management. Clear only the printed status and timestamp, remove an unprinted row from the current selection, preserve all source marks, and keep every statement in active custody totals.
