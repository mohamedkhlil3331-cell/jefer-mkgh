name: System review data preservation
description: The user's expectations for a comprehensive, department-by-department review of this system.
---

During the system review, work department by department, review the links among all system data, and do not lose existing data.

**Why:** The user explicitly requested a comprehensive review and said they do not want to lose any data.

**How to apply:** Understand a department's data and its relationships with other departments before proposing or making changes.
