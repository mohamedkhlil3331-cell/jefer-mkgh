🔐 ٢. تسجيل الدخول

شاشة موحّدة لكل الأدوار — النظام يوجّهك تلقائياً لمنطقتك

  • إدخال
    اكتب رقم الجوال + كلمة المرور ← النظام يتحقق من البيانات ويُنشئ جلسة آمنة
  • نتيجة
    يُوجَّه كل دور تلقائياً لصفحته الرئيسية: المدير ← لوحة التحكم | العميل ← الكتالوج | المشرف ← لوحة التوزيع
  • خطأ
    لو البيانات غلط ← رسالة "رقم الجوال أو كلمة المرور غير صحيحة" — الحساب لا يُقفَل تلقائياً
💡 تسجيل عميل جديد: العميل يضغط "تسجيل حساب جديد" ← يملأ بياناته ← الطلب يُرسَل للمدير للاعتماد أولاً قبل أن يتمكن من الدخول

📦 ٣. دورة حياة الطلب الكاملة

كل طلب يمر بـ ٦ مراحل إلزامية — كل مرحلة لها صاحب وإجراء محدد

١
📤 وضع الطلب
👤 العميل
  • يختار المنتج (أسمنت / بلك / مواد إنشاء) وكميته من الكتالوج
  • يُحدد موقع التسليم (من السجل أو خريطة)
  • يختار طريقة الدفع: تحويل بنكي / نقدي / آجل
  • يُرفق صورة الحوالة البنكية (عند الدفع بالتحويل)
  • يضغط "تأكيد الطلب"
يُنشأ الطلب برقم MKGH+timestamp (مثل MKGH20260701143022). الحالة: pending. تُرسَل إشعارات فورية للمراجعين
٢
✅ تأكيد الدفع
📋 المراجع
  • يفتح الطلب ويُراجع بيانات الحوالة والمبلغ
  • يضغط "تأكيد الدفع" بعد التحقق من التحويل البنكي
  • أو يضغط "رفض" مع كتابة السبب
  • للطلبات الآجلة: يُحيل الطلب للمندوب أولاً لاعتماده
عند القبول: الحالة تصبح payment_confirmed — تُرسَل إشعارات للمشرف ليُعيّن سيارة
٣
🚛 تعيين سيارة وسائق
🚛 مشرف النقليات
  • يرى الطلب في قائمة "في انتظار التعيين"
  • يختار سيارة متاحة من قائمة الأسطول (السيارات المشغولة لا تظهر)
  • يختار السائق المناسب
  • يُحدد التعريفة (بناءً على المسافة ونوع السيارة)
  • يضغط "تعيين"
الحالة: vehicle_assigned. السيارة تُحجَز وتصبح "مشغولة". السائق يستقبل إشعاراً بالطلب
٤
🧾 إصدار فاتورة التحميل
🏭 المستودع
  • يرى الطلب في قائمة "جاهز للتحميل"
  • يُراجع تفاصيل البضاعة والوزن
  • يضغط "إصدار فاتورة" — تُنشأ فاتورة رسمية بضريبة ١٥٪
  • يطبع أمر التحميل للسائق
الحالة: invoiced. الفاتورة تُحسب تلقائياً: المبلغ قبل الضريبة + ضريبة ١٥٪ + الإجمالي
٥
📸 تأكيد التحميل
🚗 السائق
  • يضغط "تأكيد التحميل" على تطبيقه
  • يلتقط صورة الحمولة المُحمَّلة ويرفعها
الحالة: loaded. العميل والمندوب يُتاح لهم رقم لوحة السيارة + رقم هاتف السائق + رابط WhatsApp مباشر
٦
🏁 تأكيد التسليم
🚗 السائق
  • يضغط "تم التسليم" عند الوصول لموقع العميل
الحالة: delivered. السيارة تُحرَّر وتصبح "متاحة" مجدداً. العميل يقدر يُقيّم الطلب وتحميل فاتورة ضريبة القيمة المضافة

حالات الطوارئ في الطلب

الإجراءمن يفعلهما يحدث
إلغاء الطلبالمديرالطلب يُحذَف، السيارة تُحرَّر إن كانت مُعيَّنة
تعديل الطلبالمديريقدر يُعدّل أي حقل في أي مرحلة (admin-edit)
تقرير عطلالسائقيُنشئ تقرير عطل مرتبط بالطلب، يُشعر مدير الورشة
رفض الطلبالمراجعالطلب يتوقف، يُرسَل إشعار للعميل بالسبب

👤 ٤. بوابة العميل

الصفحات التي يراها العميل فقط

الكتالوج (الصفحة الرئيسية)

  • تصفح
    يتصفح المنتجات مع الأسعار والتقييمات — يضغط على المنتج ليرى التفاصيل
  • طلب
    يضغط "اطلب الآن" ← ينتقل لخطوات الطلب التفصيلية
  • بحث
    يبحث بالاسم أو التصنيف — النتائج تُصفَّى فوراً

طلباتي

  • عرض
    يرى كل طلباته مع حالة كل واحد (pending / payment_confirmed / loaded / delivered)
  • مرحلة loaded
    يظهر له: لوحة السيارة، رقم السائق، رابط WhatsApp مباشر
  • مرحلة delivered
    زر "تقييم" + زر "تحميل فاتورة ضريبة القيمة المضافة"

كشف الحساب

  • عرض
    يرى إجمالي مشترياته، المدفوع، المتبقي، وسجل كل المعاملات
  • طباعة
    زر "طباعة" ← كشف حساب رسمي قابل للطباعة بشعار الشركة

رفع الحوالات البنكية

  • رفع
    يرفع صورة إيصال التحويل البنكي ← يُرسَل للمراجع للتأكيد
  • حالة
    يرى حالة كل حوالة: pending / confirmed / rejected

📋 ٥. بوابة المراجع

نقطة التحقق من الدفع قبل أي تحريك للبضاعة

الطلبات المعلّقة (Pending)

  • تأكيد الدفع
    يراجع الحوالة البنكية وصورتها ← يضغط "تأكيد" ← الطلب ينتقل لمرحلة "بانتظار السيارة"
  • رفض
    يكتب سبب الرفض ← يضغط "رفض" ← العميل يستقبل إشعاراً بالسبب
  • إحالة للمندوب
    الطلبات الآجلة ← يُحيلها للمندوب المسؤول لاعتماد حد الائتمان
  • نقدي
    طلبات الدفع النقدي ← يضغط "اعتماد نقدي" بعد التأكد من استلام النقد

الحوالات البنكية

  • عرض
    قائمة بكل الحوالات المرفوعة من العملاء مع صورة الإيصال
  • تأكيد
    يضغط "تأكيد الحوالة" ← تُسجَّل في سجل المدفوعات ويُحدَّث رصيد العميل

🚛 ٦. بوابة المشرف

مركز تعيين السيارات وتنسيق الرحلات

لوحة التوزيع

  • عرض
    بطاقات الطلبات المعتمدة في انتظار سيارة — مع تفاصيل الكمية والموقع
  • تعيين
    يختار سيارة متاحة + سائق ← يحدد التعريفة ← يضغط "تعيين" ← الطلب ينتقل لمرحلة vehicle_assigned

حالة الأسطول

  • مراقبة
    يرى كل السيارات: متاحة (أخضر) / مشغولة (أحمر) / في الصيانة (رمادي)
  • تعيين سائق دائم
    يربط سائقاً بسيارة بشكل دائم من هذه الشاشة

الرحلات النشطة

  • متابعة
    يرى كل الرحلات الجارية حالياً مع حالتها (loaded / في الطريق)
  • تنبيه التوقف
    تنبيه تلقائي إذا توقفت سيارة لأكثر من ١٠ دقائق دون تسليم

تسويات السائقين

  • إنشاء تسوية
    يُحدد مبالغ السائق المستحقة عن الرحلات المنتهية ← يُنشئ تسوية للدفع
  • عرض السجل
    سجل كل التسويات السابقة مع التواريخ والمبالغ

🏭 ٧. بوابة المستودع

إدارة عمليات التحميل وإصدار الفواتير

قائمة أوامر التحميل

  • عرض
    الطلبات التي عُيِّنت لها سيارة وجاهزة للتحميل
  • إصدار فاتورة
    يضغط "إصدار فاتورة تحميل" ← تُنشأ فاتورة بضريبة ١٥٪ ← الحالة تصبح invoiced
  • طباعة
    يطبع أمر التحميل ← يُعطيه للسائق لاصطحابه

إدارة المخزون (المستودع)

  • مستويات المخزون
    يرى الكميات الحالية لكل منتج في كل فرع
  • استلام بضاعة
    يسجل كميات الوارد الجديد ← يُحدَّث المخزون تلقائياً
  • تنبيهات النفاد
    تنبيه أحمر عند اقتراب أي صنف من الحد الأدنى للمخزون

🚗 ٨. بوابة السائق

واجهة مُحسَّنة للجوال — بسيطة وسريعة

  • عرض طلباتي
    يرى كل الطلبات المُعيَّنة له مع التفاصيل: العميل، الموقع، البضاعة
  • تأكيد التحميل
    يضغط "تم التحميل" + يرفع صورة ← الحالة تصبح loaded ← العميل يُشعَر
  • تأكيد التسليم
    يضغط "تم التسليم" ← الحالة تصبح delivered ← السيارة تتحرر
  • تقرير عطل
    يضغط "إبلاغ عن عطل" ← يكتب الوصف ويرفع صورة ← إشعار فوري لمدير الورشة
  • وثائقي
    يرى حالة وثائقه (رخصة القيادة / الإقامة / البطاقة الصحية) وتواريخ انتهائها

🤝 ٩. بوابة المندوب

متابعة العملاء والطلبات الآجلة

  • طلبات عملائي
    يرى كل طلبات العملاء المرتبطين به — مع حالة كل طلب
  • اعتماد آجل
    المراجع يُحيل له الطلبات الآجلة ← يُراجع حد الائتمان ← يوافق أو يرفض
  • كشف حساب العميل
    يرى رصيد كل عميل والمستحقات عليه
  • أهدافي
    يرى أهداف المبيعات الشهرية ومدى تحقيقها

🚛 ١٠. دفتر السيارات (Fleet Management)

سجل شامل لكل مركبات الشركة ووثائقها

قائمة المركبات

  • عرض
    جدول بكل المركبات: اللوحة، النوع، الحالة (متاح / مشغول / صيانة)، السائق المرتبط
  • إضافة مركبة
    يملأ بيانات المركبة (اللوحة، نوع السيارة، السعة) ← تُضاف للنظام وتصبح متاحة للتعيين
  • تعديل
    تعديل أي بيانات للمركبة — النوع، الحالة، السائق المرتبط
  • حذف
    إزالة المركبة من النظام (تأكيد مطلوب)

وثائق الامتثال

  • عرض الوثائق
    يرى وثائق كل مركبة: التأمين، الفحص الدوري، بطاقة التشغيل — مع تاريخ الانتهاء
  • رفع وثيقة
    يرفع ملف PDF/صورة للوثيقة الجديدة مع تاريخ البداية والانتهاء
  • تنبيه الانتهاء
    النظام يُنبّه تلقائياً عند اقتراب انتهاء أي وثيقة (٣٠ يوم مسبقاً)

تحليلات المركبة

  • لوحة التحليل
    لكل مركبة: عدد الرحلات، إجمالي الإيراد، تكاليف الصيانة، سجل السائقين
  • سجل الأعطال
    كل تقارير الأعطال المرتبطة بهذه المركبة مع تواريخها وتكاليف الإصلاح

🧑‍✈️ ١١. إدارة السائقين

ملفات السائقين ووثائقهم

  • قائمة السائقين
    كل السائقين مع حالة وثائقهم (الإقامة / رخصة القيادة / البطاقة الصحية)
  • إضافة سائق
    يُدخل بيانات السائق ← يُنشأ ملف كامل
  • ربط بمستخدم
    يربط ملف السائق بحسابه في النظام ← يُتاح له تسجيل الدخول كـ driver
  • تنبيه وثائق
    النظام يُبرز السائقين الذين وثائقهم منتهية أو قريبة من الانتهاء بلون أحمر/أصفر
  • طلبات الوثائق
    السائق يطلب تجديد وثيقة ← المسؤول يتابع ويُحدّث

🔧 ١٢. الورشة وصيانة المركبات

إدارة أعمال الصيانة من لحظة البلاغ حتى الإغلاق

تقارير الأعطال

  • استلام بلاغ
    السائق يرفع بلاغ عطل ← يظهر فوراً لمدير الورشة مع صورة العطل ووصفه
  • إنشاء أمر عمل
    من البلاغ ← يضغط "إنشاء أمر عمل" ← ينتقل تلقائياً لصفحة أوامر العمل مع بيانات المركبة
  • تحديد الجهة
    يُحدد المسؤول: السائق (إهمال) / المركبة (تآكل طبيعي) / الشركة

أوامر العمل (Work Orders)

  • إنشاء أمر عمل
    يُدخل: المركبة، وصف العمل، قطع الغيار المطلوبة، مصدر التكلفة (مخزون / خارجي)
  • مصدر التكلفة
    inventory: يخصم قطع الغيار من مخزون الورشة تلقائياً | vehicle: يُضيف التكلفة لسجل المركبة
  • تتبع الحالة
    open ← in_progress ← done — كل تحديث يُسجَّل بالتاريخ والوقت
  • إغلاق الأمر
    يُدخل التكلفة الفعلية ← يضغط "إتمام" ← الأمر يُغلَق والتكاليف تُسجَّل في سجل المركبة

بطاقات الصيانة الدورية

  • عرض
    سجل كامل لكل عمليات الصيانة الوقائية لكل مركبة
  • إضافة بطاقة
    يُسجّل: نوع الصيانة، الكيلومترات، التاريخ، قطع الغيار المستخدمة

📦 ١٣. مخزون قطع الغيار

رقابة دقيقة على كل قطعة في الورشة

إدارة المخزون

  • قائمة القطع
    كل قطع الغيار مع: الكمية الحالية، الحد الأدنى، متوسط التكلفة، الوحدة
  • إضافة صنف جديد
    يُدخل اسم القطعة، وحدة القياس، الحد الأدنى ← يُضاف للمخزون بكمية صفر
  • تعديل الكميات
    تعديل يدوي للمخزون مع سبب التعديل (توالف / جرد / تصحيح)
  • تنبيه النفاد
    عند الوصول للحد الأدنى ← تنبيه أحمر لمدير الورشة والمشتريات لرفع طلب شراء

سجل الحركات

  • عرض الحركات
    كل عملية صرف أو استلام مع: التاريخ، رقم أمر العمل، الكمية، المرجع
  • تصدير Excel
    يُصدر المخزون الكامل أو سجل الحركات لملف Excel
  • استيراد Excel
    يرفع ملف Excel لإضافة أصناف جديدة بالجملة

👥 ١٥. الموارد البشرية والموظفين

إدارة الكوادر البشرية وطلباتهم

ملفات الموظفين

  • قائمة الموظفين
    كل الموظفين مع: المسمى الوظيفي، القسم، تاريخ التعيين، الراتب، حالة الوثائق
  • إضافة موظف
    يُدخل بيانات الموظف الكاملة ← يُنشأ ملف رسمي في النظام
  • تعديل
    تحديث الراتب، القسم، المسمى، الوثائق

طلبات الموارد البشرية

  • أنواع الطلبات
    إجازة سنوية / مرضية / طارئة / سلفة / شهادة عمل / غيرها
  • رفع طلب
    الموظف يرفع طلبه من بوابة الموظف ← يُشعَر المدير
  • اعتماد/رفض
    المدير يوافق أو يرفض مع إضافة ملاحظة ← الموظف يُشعَر بالنتيجة

بوابة الموظف (Self-Service)

  • راتبي
    يرى تفاصيل راتبه الشهري والخصومات والبدلات
  • طلباتي
    يرفع طلباته ويتابع حالتها
  • مصروفاتي
    يرفع مصروفات العهدة (Petty Cash) ← المحاسب يعتمدها ويصرفها

  • أسعار الكيلومتر

⚙️ ١٧. الإدارة والإعدادات

صلاحيات المدير الكاملة

إدارة المستخدمين

  • إنشاء مستخدم
    يحدد الدور، رقم الجوال، كلمة المرور ← يُنشأ الحساب فوراً
  • تخصيص الصلاحيات
    لكل مستخدم: تُفعَّل/تُعطَّل صلاحيات محددة (مستقلة عن الدور)
  • إيقاف الحساب
    يُوقف حساب مستخدم مؤقتاً دون حذفه — يمنعه من تسجيل الدخول
  • اعتماد التسجيل
    طلبات التسجيل الجديدة تظهر للمدير ← يوافق ← يُتاح للعميل الدخول

إعدادات الشركة

  • بيانات الشركة
    اسم الشركة، العنوان، الشعار، بيانات الاتصال — تظهر في الفواتير والتقارير
  • إعدادات الفاتورة
    تخصيص رأس وتذييل الفواتير، شروط الدفع، ملاحظات إضافية
  • نقاط التحميل
    يُدير المصانع والمستودعات (نقاط التحميل) — الاسم، المدينة، الإحداثيات
  • أنواع المركبات
    يُعرّف أنواع المركبات (سطحة / بلكر / ونش / دين) وسعتها وأنواع البضاعة

سجل النظام (Audit Log)

  • عرض
    كل الإجراءات المنفَّذة: من فعلها، متى، على أي سجل — سجل لا يُحذَف
  • تصفية
    بحث حسب المستخدم، نوع الإجراء، الفترة الزمنية

المكتبة القانونية

  • الأنظمة السعودية
    مكتبة الأنظمة واللوائح ذات الصلة بالشركة
  • الجلسات القضائية
    تتبع جلسات المخالفات المرورية وقضايا الشركة
